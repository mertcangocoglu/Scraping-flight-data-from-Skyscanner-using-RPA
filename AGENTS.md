## Architecture

- **Pattern**: REFramework / transactional state machine.
- **Data flow**: Configuration is loaded from `Data\Config.xlsx`; transaction data is obtained through the framework; `Framework\Process.xaml` maps and validates inputs, navigates and filters Skyscanner, extracts results, and writes them to Excel.
- **Execution flow**: Initialize applications/settings → get transaction data → process the current transaction → set transaction status → retry or continue → close applications.
- **External integrations**: Skyscanner website through Chrome UI automation, Excel workbooks, and the UiPath transaction/queue framework.
